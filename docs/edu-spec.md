# 教育版アプリ「宇宙からの目」仕様書

## 1. 概要

### 1.1 背景

現在の衛星可視化アプリは、FOV（視野角）、オフナディア角、TLE（Two-Line Element）などの専門知識を前提とした技術者向けUIで構成されている。
本仕様書は、**日本の小学校高学年（10〜12歳）が授業で使える教育版**を、同一リポジトリ内に `/edu` ルートとして構築するための仕様を定義する。

### 1.2 ターゲットユーザー

- **主ユーザー**: 日本の小学5〜6年生（10〜12歳）
- **利用環境**: GIGAスクール端末（iPad / Chromebook）、横向き（landscape）
- **利用シーン**: 理科の授業で生徒が各自のタブレットで操作。先生がプロジェクターで画面共有しながら説明

### 1.3 コンセプト

**「宇宙からの目 — 地球観測を体験しよう」**

- 人工衛星が宇宙から地球をどう見ているかを体験できる
- 動く楽しさ、操作できる楽しさを重視
- 専門用語を使わず、身近なものとの比較で直感的に理解

### 1.4 開発フェーズ

| Phase       | 内容                     | スコープ                        |
| ----------- | ------------------------ | ------------------------------- |
| **Phase 1** | 衛星カード + 簡易UI      | 既存機能を教育向けUIに再構成    |
| Phase 2     | 打ち上げシミュレーション | 自分で衛星を設計して軌道を確認  |
| Phase 3     | 解像度・センサー比較     | 光学 vs SAR、解像度の違いを体感 |
| Phase 4     | ミッションチャレンジ     | ゲーム的要素で学びを深める      |

## 2. 設計方針

| 項目             | 決定事項                      | 理由                                                 |
| ---------------- | ----------------------------- | ---------------------------------------------------- |
| アプリ構成       | 同一リポジトリ、`/edu` ルート | Cesiumバンドル共有、Worker再利用                     |
| ルーティング     | React Router + React.lazy     | コード分割で既存アプリに影響なし                     |
| 画面向き         | 横向き（landscape）優先       | Cesiumの3D表示に最適、GIGA端末はキーボード付きが多い |
| カードトーン     | 図鑑風（情報量多め）          | 学びの資料としても使える                             |
| 物理精度         | 定性的に正確                  | 傾斜角で軌道が正しく変わる、周期が概算で正しい       |
| stepSec          | 固定30秒                      | タブレット負荷軽減（現在の5秒の6倍軽量）             |
| フォント         | 16px以上                      | タブレットでの視認性確保                             |
| タッチターゲット | 最小44x44px                   | Apple HIG / WCAG 2.5.5 準拠                          |

## 4. データモデル

### 4.1 教育メタデータスキーマ

`src/data/edu-satellite-metadata.ts` に定義。既存 `sample-tle.json` の `id` フィールドで紐づけ。

```ts
export interface EduSatelliteMetadata {
  /** sample-tle.json の id と一致 */
  id: string;

  /** 子供向け表示名（カタカナ表記） */
  displayName: string;

  /** カテゴリアイコン */
  iconType: "optical" | "sar" | "weather";

  /** カードのアクセント色 */
  cardColor: string;

  /** ミッション説明（2-3文、小学生向け） */
  missionDescription: string;

  /** 運用機関 */
  operator: string;

  /** 国/地域（絵文字 + 名前） */
  origin: string;

  /** 高度と身近な比較 */
  altitude: {
    km: number;
    comparison: string; // 例: "飛行機の約80倍の高さ"
  };

  /** 解像度と身近な比較 */
  resolution: {
    meters: number;
    comparison: string; // 例: "バスくらいの大きさが見える"
  };

  /** センサー種類の子供向け説明 */
  sensorType: {
    type: "光学" | "SAR（レーダー）" | "赤外線";
    explanation: string; // 例: "人の目と同じように光を使って写真をとるカメラ"
  };

  /** この衛星でわかること（3-4項目） */
  capabilities: string[];

  /** 面白い豆知識 */
  funFact: string;
}
```

### 5.3 各コンポーネント仕様

#### EduGlobe

- 既存 `GlobeRenderer` をラップ
- FPS監視・stepSec動的調整: **無効**（固定30秒）
- NightShade: **常時OFF**（視認性優先）
- 初期カメラ: 日本上空（35N, 137E, 高度15,000km）
- ホームボタンのみ表示

#### EduSatelliteLayer

- ポイントサイズ: **16px**（現在の倍）
- ラベル: **14px**、日本語表示名（`displayName`）
- 軌道ライン: 全衛星で常時表示、太さ2px

#### EduFootprintLayer

- **選択中の衛星のみ**表示
- スポットライト風: `alpha=0.4`、グロー効果付きアウトライン
- パルスアニメーション（CallbackPropertyで透明度を周期変化）

#### SatelliteCard（図鑑風）

- カード幅: 200px、高さ: カルーセル領域いっぱい
- `scroll-snap-align: start`
- タップ → 衛星選択 + Globeフライ
- 選択状態: ボーダーが衛星カラーに光る
- 「くわしく」ボタン → モーダル表示

#### SatelliteInfoModal

- 全画面オーバーレイ
- 左半分: 衛星の詳細情報（図鑑の1ページ風）
- 右半分: リアルタイム位置情報
  - 緯度・経度（地図上のどこにいるか）
  - 高度（km）
  - 速度（km/s → 身近な比較）
- 閉じるボタン: 右上 ✕（48px）

#### EduTimeController

- 再生/一時停止: 大きめ48pxボタン
- 速度: ×10, ×60, ×300 の3段階
- スライダー: ±3日
- 時刻表示: 「3月6日 15:30」形式（JST固定、UTC非表示）

### 5.4 インタラクションフロー

1. **初期表示**: 地球儀に10機の衛星が動いている。時間は ×60 で再生中
2. **カードスクロール**: 下部のカードを横スクロールして衛星を探す
3. **衛星選択**: カードタップ → Globeがその衛星にフライ → フットプリント（スポットライト）表示
4. **詳細確認**: 「くわしく」ボタン → 図鑑モーダルが開く（リアルタイム位置も表示）
5. **時間操作**: 早送りで衛星の動きを確認。地球の周りを回る様子を観察
6. **別の衛星に切替**: 別のカードをタップ → 前の衛星のフットプリントが消え、新しい衛星にフライ

## 7. 将来Phase詳細

### Phase 2: 打ち上げシミュレーション

**コンセプト**: 自分で衛星を設計して打ち上げるシミュレーション

**操作パラメータ**（専門用語を使わない）:

- **高さスライダー**: 200km〜36,000km（「低い〜高い」）
- **傾きスライダー**: 0°〜98°（「赤道の上を回る〜北極と南極を通る」）
- **カメラの性能**: 「よく見える（狭い範囲）」vs「広く見える（ぼんやり）」

**表示**:

- 設定した軌道を地球儀上にリアルタイム表示
- 「あなたの衛星は1日で地球を○周するよ！」
- 「日本の上を1日に○回通るよ！」
- 物理精度: 定性的に正確（ケプラー軌道の簡易計算で十分）

### Phase 3: 解像度・センサー比較

**解像度体験**:

- 地図上のある地点（例: 学校の周辺）を異なる解像度で表示
- 0.3m → 車のナンバーが見える、10m → 建物が見える、500m → 町の形が見える
- 地図のズームレベルで疑似体験

**光学 vs SAR**:

- 同じ場所を2画面で比較
- 光学: 「目で見たのと同じ写真」「雲があると見えない」
- SAR: 「電波で撮った白黒の写真」「雲があっても見える」「夜でも撮れる」
- **天気トグル**: 雲を表示 → 光学は真っ白、SARはそのまま！

### Phase 4: ミッションチャレンジ

ゲーム的要素で学びを深める:

- 「日本全体を1日で撮影せよ！」
- 「災害が起きた場所をすぐに撮影せよ！」
- 「夜の海を観察せよ！」（→ SARを選ぶと正解）
- 条件に合う衛星パラメータを設計する問題形式

## 8. 技術的考慮事項

### 8.1 タブレット性能

- GIGAスクール端末はiPad（9th gen）やChromebookが主流
- WebGL性能が限られるため:
  - `stepSec = 30` 固定で計算量を1/6に削減
  - スワスは非表示（Worker計算パスを1つ削減）
  - 衛星ポイントやラインの描画はEntity APIで十分

### 8.2 コード分割

- `React.lazy(() => import("./edu/EduApp"))` によりeduコードは遅延ロード
- `/` にアクセスした場合、教育版のコードは一切ダウンロードされない
- Cesiumバンドル（~4MB）はどちらのルートでも共有

### 8.3 既存アプリへの影響

- `src/main.tsx` にルーター追加のみ
- 既存コンポーネントの変更なし
- 共有ライブラリ（`src/lib/`, `src/hooks/`, `src/workers/`）の変更なし
- CSSは `src/edu/` 内に閉じる（既存CSSに影響なし）

## 9. 受け入れ基準（Phase 1）

1. `/` で既存アプリが従来通り動作する
2. `/edu` で教育版が表示される
3. Globe上に10機の衛星が大きめポイント + 日本語名で表示
4. 下部にカード式の衛星一覧が横スクロールで表示される
5. カードタップでGlobeがその衛星にフライし、フットプリントがスポットライト風に表示される
6. 詳細モーダルに図鑑風の情報とリアルタイム位置が表示される
7. 時間操作（再生/停止/速度変更）が動作し、時刻がJSTで表示される
8. iPad相当（1024x768）で全要素がタッチ操作可能
9. 10機表示 + stepSec=30 で滑らかに動作する
